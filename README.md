# A-MacroPad
A customisable Macro Pad powered by the XIAO Seeed Studio RP2040, with a 3.5 inch screen and my own fully orginial PCB. 

HOW To USE:
This is a fully customisable macropad where you could do a lot of things! Customize each key to complete its own function and more.
